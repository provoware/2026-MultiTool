Kurz erklärt

Der Systemstatus zeigt sichere Basisinformationen zu diesem Gerät und zum Programmkern. Ein normaler Zustand bedeutet, dass die geprüfte Grundlage bereit ist. Eine Warnung bedeutet, dass ein angezeigter Punkt Aufmerksamkeit braucht. Sie müssen nicht allein wegen einer Warnung sofort etwas verändern.

Schritt für Schritt
  1. Öffnen oder betrachten Sie den Bereich Systemstatus.
  2. Lesen Sie den sichtbaren Status.
  3. Beachten Sie bei einer Warnung den bereits vorhandenen Hinweis.
  4. Führen Sie keine Änderung durch, die das Programm selbst nicht bereits anbietet.
